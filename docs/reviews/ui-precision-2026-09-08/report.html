AxiBridge, before and after

Every pair uses the same fixed recipes, fresh isolated configuration, local fonts, viewport and interaction sequence. The captures exercise the real server and browser UI; they do not touch the running app, user projects or hardware.

The pair verifier passed all 28 scenarios. It compares complete source and process recipes, SVG drawing geometry and rendered animation image bytes. Backend-generated UUID references inside tween recipes are normalized to stable fixture-layer order before comparison; rendered geometry and image bytes are not normalized. Live simulator percentages, position and remaining time are recorded separately as time-dependent UI.

Zoom method: Playwright does not expose Chromium’s browser UI zoom. One case uses document.documentElement.style.zoom = '2' as a documented approximation. The closer supplement uses a 720×450 CSS viewport at device scale factor 2, producing a 1440×900 pixel image while viewport units and media queries see the reduced layout. Both are browser emulations, not a native zoom assertion.
