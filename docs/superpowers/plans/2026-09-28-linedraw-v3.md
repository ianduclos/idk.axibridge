# Linedraw v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Make both linedraw research approaches usable inside AxiBridge with automatic, correctable face regions and portable, executable pen geometry.

**Architecture:** A new source consumes image assets and a persisted recipe. A local worker produces bounded model evidence; a cancellable job manager serves a dedicated drawing bench. Accepted layers use the existing session, resolve, save and plot paths.

**Tech Stack:** Python/FastAPI/Pydantic, NumPy/SciPy/Shapely/contourpy, optional local PyTorch/torchvision and MediaPipe workers, vanilla ES modules, existing bench host and Playwright harness.

**Spec:** [Approved design](../specs/2026-09-28-linedraw-v3-design.md).

## Global Constraints

- It does not replace `linedraw` or `lineart_*`.
- Processing is local.
- Reference photographs, their geometry, annotations and intermediate maps remain outside Git.
- No downloads on generation or project open.
- Facial landmarks may locate a region; they are never emitted as drawing strokes.
- The existing asset store, layer model, project serialization and single resolve path remain authoritative.
- Model code/checkpoints live in a configured external model directory.
- Do not change the application's pinned Python to solve conflicts.
- Inspect current machine state before restarting anything; never interrupt an active plot.
- An unavailable-model stub or a wrapper around private scripts is not a completed integration.

## Review Focus

1. A rotated phone photograph must keep corrected regions aligned after save/reopen (Tasks 1, 5, 6).
2. A second image or late result must never receive the first image's guides or geometry (Tasks 3, 5).
3. A face-free or low-contrast image must yield an honest empty/fallback state, not fabricated detail (Tasks 2, 4).
4. Dense dark regions must preview the strokes actually sent to the pen, with bounded geometry and valid holes (Tasks 4, 6).
5. Opening a saved project on a machine without ML must retain its geometry; regeneration failure must not destroy it (Tasks 3, 6).

Use an isolated worktree from the current approved checkpoint. The current branch

## File map and shared contracts

New production package `axibridge/linedraw/`:

- `contracts.py`: immutable validated recipes, face regions, model identity,
  candidate/evidence types and explicit resource limits.
- `runtime.py`, `worker.py`: setup/status, subprocess lifecycle and model adapters.
- `jobs.py`: revision-bound analysis/render jobs and bounded evidence cache.
- `trace.py`: learned-map and photographic-contour tracing.
- `engine.py`: deterministic selection, shading and paper-coordinate output.
- `geometry.py`, `shadows.py`, `flow_hatch.py`: production copies of generic
  research kernels, preserving behavior and synthetic coverage.

New `axibridge/linedraw_api.py` owns `/api/linedraw/*`; include it from
`axibridge/app.py`. New source `axibridge/sources/linedraw_v3.py` registers the
generator and bench. `static/js/linedraw_bench.js` owns its user interaction;
`static/js/linedraw_regions.js` owns the region editor. Register the adapter in
`static/js/process.js`. Reuse existing CSS variables and bench lifecycle.

New `tools/setup_linedraw.py` validates/configures external runtime files;
`docs/LINEDRAW.md` documents installation, controls, limitations and model terms.
Modify research imports to use production kernels without changing their tests'
meaning. Add source readiness support in `registry.py` only if required by the
browser; preserve existing sources' default available state.

```python
# contracts.py: canonical image frame is EXIF-corrected and unrotated.
class FaceRegion(BaseModel):
    model_config = ConfigDict(extra="forbid", allow_inf_nan=False)
    id: str = Field(min_length=1, max_length=64)
    cx: float = Field(ge=0, le=1)
    cy: float = Field(ge=0, le=1)
    rx: float = Field(gt=0, le=0.5)
    ry: float = Field(gt=0, le=0.5)
    enabled: bool = True
    origin: Literal["automatic", "manual"] = "manual"

@dataclass(frozen=True)
class Candidate:
    points: np.ndarray  # Nx2 canonical working-image pixels
    confidence: float
    identity: str

@dataclass(frozen=True)
class Evidence:
    rgb: np.ndarray             # HxWx3, float32 in [0,1]
    foreground: np.ndarray      # HxW probability
    normals: np.ndarray | None  # HxWx3; required by form modes
    whole_lines: np.ndarray    # HxW whiteness
    tiled_lines: np.ndarray    # HxW whiteness
    faces: tuple[FaceRegion, ...]
    face_candidates: dict[str, tuple[Candidate, ...]]
    identity: str              # content + inference settings + model identity

# Stable seams; optional callbacks are supplied by the calling job/source.
def detect_and_analyze(image_bytes: bytes, params: dict, *, cancel,
                       progress) -> Evidence: ...
def render_document(evidence: Evidence, params: dict, *, checkpoint) -> PathDocument: ...
```

`params` at these seams is a validated `LinedrawV3Params.model_dump()` dictionary,
not arbitrary request JSON. Validate finite array shapes and size limits before
constructing Evidence. Do not deserialize arbitrary pickle results.
