## Changed studies

**`ledger_straight` v2.** Ian: "keep the lines inside stylized. top and bottom
straight (as option) is good" and "like the normal text tbh".

- The default is now `text`: the lettering is plain and every rule is
  hand-drawn.
- `frame+text` is the new option: it keeps only the full-width rules straight
  (the top double rule and the bottom rule). `frame` and `none` are also
  offered.

**`sampler` v2** adds **Keep it clean**, off by default. It tidies the same
combination by rule, with no new draw from the seed:

- A straight-run machine voice (compass, ruler, stair or koch) speaks its own
  hand instead.
- A handover to one of those machines is dropped.
- A measurement laid beside the drawing is dropped.
- A scatter of copies becomes one surface.

A layer kept from v1 keeps its sample key, so it draws the same combination
(a test checks this). "Save as new study" from a sampler keeps only the seed
control.

## Taxonomy graph: the rework

Ian on the length histogram: "feels detached". The new default graph is
`hist: strip`, "the line laid straight":

- Every specimen is placed in the order it was drawn, turned so its chord lies
  on one baseline, and set where the previous one ended. The result is the
  drawing's own line, straightened.
- It is cut and labelled exactly like the plate (A3, C1, …), with a tick at
  each cut.
- It wraps into rows like writing, all at one scale, so each span's width is
  that specimen's chord.

So the graph is drawn by the same line and tied to both the plate and the
drawing. I also tried the line's κ(s) as a seismograph strip. It was too spiky
to read, so I dropped it.

## Research-side changes (all additive)

- `measure_next`: `hist: "strip"` (`plate_strip`) and `numbers`.
- `voices_machine_diagram.straight_flags`: `frame` and `frame+text`.
- `swell` renderer: `dots`, `dot_shape`, `dot_size`, `dot_gap` and `dot_scale`.
  - Count groups slide past their mass, because on a bold line the count events
    sit inside the swells.
  - Turns dots skip the masses.
  - `dot_plan` gained an optional `avoid` argument.
- `sampler.sample(clean=)` plus `tidy()`.

**Parity:** these recipes give byte-identical ink digests before and after the
changes:

- 53 round-10/11 recipes: every measure_next recipe and cell, swell
  bold/combo/dots/profiles, pair_ledger and the three ledger_straight review
  recipes;

The freeze then reproduced every study fixture through the frozen copy. Parity
holds exactly under the app's GEOS 3.13 too, so I added no study to
GEOS_SENSITIVE.
