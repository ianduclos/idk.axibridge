## Findings and status

1. **Fair Pollock set never dropped `rel_`** (`discriminate.py`; group name is
   `"rel"`) — the "fair" numbers equalled the geometry-only ones.
   **Fixed** (`fix(gesture): review fixes…`).
2. **Nulls pass through a band-limiting pipeline the real drawings don't.**
   An identity "null" (same κ, re-integrated) separates from real Matisse at
   AUC 0.92–0.95. **Fixed:** `nulls.identity` added; the report now shows
   each null vs identity as the gate number.
3. **σ/w confound** — σ is set from ref only, line width in px is a
   per-collection constant. **Partly addressed:** `panel` gains
   `sigma_min_w`; run v3-sw3 floors σ at 3 line widths. A full fix is to
   re-extract every scan at a common line width in px.
4. **Grammar memorisation metric** cannot tell quoting from speaking for
   single-segment strokes. **Open:** report on multi-segment strokes only,
   add a shuffle-trained control grammar, run stage-3 test 1.
5. **CV without groups** (a sheet and its nulls could straddle folds) —
   checked: grouping *raised* null AUCs 0.01–0.04, so it was a deflating
   leak. **Fixed anyway** (StratifiedGroupKFold).
6. Null `ref_length` drifts (median +2–5%, up to +45% on single drawings).
   **Open, low impact** once (2) is the comparison.

Also from the reviewer: the headline "7-class balanced accuracy" is padded by
four easy null classes; the honest artist number is artists-only,
geometry-only: 0.68 (logreg) / 0.74 (forest), chance 0.33. The report now
prints it separately.

## What this means for the plan

- Stage 1 gate (extraction good enough): **met** for κ at the panel scale.
- Stage 2 gate (hand, not noise; artists separable without thickness):
  **null half met** under the matched control; **artist half not yet
  shown** — the medium/scan confound must be removed first (common line
  width; medium-matched comparison, e.g. Matisse etchings vs another
  etcher).
- Stage 3: the preview is a sketch, not a result. Segment fitting at
  σ = 0.01·ref collapses most strokes to one segment — the grammar needs a
  finer scale or a different alphabet before it can carry order.
